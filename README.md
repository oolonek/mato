# mato

Mato coordinates the flock: it runs the chosen steps that turn a research dataset into a linked record of samples, measurements, and possible chemical matches. It tells the other species when to work; it does not download data or claim that a possible match identifies a chemical.

The name Mato refers to a lizard: the giant ameiva, *[Ameiva atrigularis](https://www.wikidata.org/wiki/Q2842576)* ([Catalogue of Life: 66B76](https://www.catalogueoflife.org/data/taxon/66B76)).

## In the flock

After a dataset has been downloaded, Mato brings together checking, storage, feature extraction, and comparison with reference spectra. The final knowledge graph is exported separately from the resulting record.
